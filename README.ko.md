# Spotter — Weather-Aware Truck Routing

[English](./README.md) · 영문 `README.md`의 한국어판입니다. 영문이 기준입니다.

트럭 운전자가 **날씨, 적재 중량, 이동 시간**을 고려해 가장 안전한 경로를 고를 수 있도록 돕는 웹 앱입니다. (React + Django)

## 이 앱이 하는 일

1. **입력 받기** — 출발지/도착지, 출발 일시, 적재 중량을 입력합니다.
2. **경로 3개 생성** — routing API로 대안 경로 3개를 만듭니다.
3. **경로 위 날씨 확인** — 경로를 10 / 25 / 50마일 간격으로 나누고, 트럭이 각 지점에 **도착할 예상 시각** 기준의 날씨(풍속·강우·강설)를 가져옵니다.
4. **위험도 판정** — 날씨를 `Low / Moderate / High / Severe / No Travel`로 분류하고, 적재 중량이 무거울수록 강풍 구간의 위험 등급을 높입니다.
5. **최적 경로 추천** — 아래 순서로 비교해 가장 안전한 경로를 추천합니다.
   1. Severe 구간이 가장 짧은 경로
   2. High 구간이 가장 짧은 경로
   3. 평균 위험도가 가장 낮은 경로
   4. 이동 시간이 가장 짧은 경로
6. **지도 시각화** — 모든 경로, 체크포인트, 위험 수준, 도착 예상 시각(ETA), 경로 요약을 지도에 표시하고, 경로 주변 **날씨 heatmap**을 **0–48시간 forecast 슬라이더**로 확인할 수 있습니다.

## 위험 판정 요약

| 조건 | Low | Moderate | High | Severe | No Travel |
|---|---|---|---|---|---|
| 풍속 | < 25 mph | 25–34 | 35–44 | 45–54 | ≥ 55 mph |
| 강우 | < 0.10 in/hr | 0.10–0.25 | 0.25–0.50 | 0.50–1.00 | > 1.00 |
| 강설 | < 0.5 in/hr | 0.5–1.0 | 1.0–2.0 | 2.0–3.0 | > 3.0 |

적재 규칙:

- 풍속 ≥ 55 mph → 적재량과 관계없이 **No Travel**
- 풍속 45–54 mph + 적재 > 30,000 lb → **No Travel**
- 풍속 35–44 mph + 적재 > 40,000 lb → **Severe**

## 화면 구성

- **지도** — 조용한 회색 베이스맵 위에 경로 3개를 함께, **모두 위험도 색으로** 보여줍니다: 각 경로선은 위험도에 따라 구간별로 색이 다릅니다. 선택한 경로는 굵고, 출발지에서 도착지까지 그려집니다(짧은 애니메이션). 나머지 경로는 더 가늘고 옅습니다. **모든 경로의 모든 체크포인트가** 등급 색의 **점**으로 표시됩니다. 선택한 경로의 체크포인트에는 위험 등급 색 테두리의 흰 원 안에 날씨 그림(잔잔함, 약한 비, 비, 눈, 바람)도 표시됩니다. 그림이 겹치는 곳(긴 경로를 한눈에 볼 때)에서는 일부를 생략하되 더 나쁜 등급을 남기고, 그 아래의 점은 그대로 남습니다. 아주 긴 경로를 한눈에 볼 때는 점도 작아지다가 결국 선에 자리를 내줍니다. 선은 체크포인트가 대표하는 구간마다 잘려 있어 색으로 각 체크포인트의 등급을 보여줍니다. 범례는 항상 보이고, 지도는 경로에 맞춰 확대할 때 범례·경로 요약 바·슬라이더가 경로를 가리지 않게 합니다.
- **경로 카드** — 경로마다 숫자 4개만 보여줍니다: 심각(Severe) 마일 / 높음(High) 마일 / 평균 위험 / 소요 시간. (화면 문구는 영어: `Severe mi`, `High mi`, `Avg risk`, `Duration`) 그 아래의 얇은 막대와 한 줄이 경로의 마일이 등급별로 어디에 있는지 알려줍니다("All Low along the route" 또는 "Low 980 mi · Moderate 26 mi"). 반 마일보다 짧은 구간은 0이 아니라 "<1"로 표시합니다.
- **추천 이유** — 추천 경로에 이유를 2위 경로와 비교해 한 줄로 표시합니다. (예: "Fewer severe miles than Route B (0 vs 25), 20 min slower than Route B.")
- **체크포인트** — 각 체크포인트에 도착 예상 시각(ETA)과 그 시각의 날씨, 위험 등급을 함께 보여줍니다. 지도나 목록에서 하나를 누르면 풍속·강우·강설이 값과 등급이 있는 그림 타일 세 개로 나타납니다. 목록은 처음 10개를 보여주고 `Load more`와 `Show all`로 더 볼 수 있습니다.
- **운행 금지 경고** — No Travel 구간이 있으면 경고 배너로 크게 표시합니다.
- **forecast 슬라이더** — 0–48시간 슬라이더를 움직이면 날씨 heatmap과 지도 위 트럭 예상 위치가 함께 바뀝니다. 0시간은 출발 시간대(출발 시각을 가장 가까운 정시로 맞춘 값)이고, 고른 시각의 날짜·시간이 슬라이더 옆에 표시됩니다. 48시간 전체를 한 번에 받아 두므로 슬라이더를 움직여도 서버를 호출하지 않습니다.

## 규칙 해석과 가정

과제 문서가 명시하지 않은 부분은 아래와 같이 정했습니다.

**입력**

- 장소는 **미국 안에서만** 찾습니다. From / To 입력란은 입력하는 동안(3자부터) 일치하는 장소·주소·도시를 목록으로 보여주고, 버튼으로 브라우저의 현재 위치를 채울 수 있습니다. 목록에서 고르지 않고 입력만 한 글자는 **첫 번째 일치 결과**로 정해지며, 찾은 이름을 화면에 보여주므로 잘못 찾은 경우를 알아볼 수 있습니다. 미국 밖의 장소는 거부합니다(요청을 손으로 만들어 보내도 마찬가지입니다).
- 화면의 모든 시각은 **브라우저의 시간대**입니다(폼과 체크포인트 목록 옆에 시간대 이름을 표시합니다). API는 UTC로 주고받습니다.
- 5분 전까지의 출발 일시는 받습니다. 폼의 "지금"은 서버에 닿을 때 이미 몇 초 지나 있기 때문입니다. 그보다 이전은 거부합니다.
- 출발지와 도착지가 같은 장소면 거부합니다.
- 라우팅 서비스는 경로를 "최대 3개" 줍니다. 더 적게 오면 받은 만큼만 보여주고 그 사실을 알립니다("Only 2 routes available for this trip."). 경로를 지어내지 않습니다.
- 요청은 클라이언트 주소별로 제한합니다(분당 6회, 하루 60회 분석). 분석 한 번이 모든 방문자가 함께 쓰는 무료 할당량을 쓰기 때문입니다. 제한을 넘으면 얼마나 기다려야 하는지 알려줍니다.

**위험 등급**

- 체크포인트의 등급은 풍속·강우·강설 등급 중 **가장 높은 것**입니다. 적재 규칙은 이 등급을 올리기만 하고 내리지 않습니다.
- 풍속은 지속 풍속(sustained wind speed)을 사용합니다. 돌풍(gust)은 사용하지 않습니다.
- 풍속 표는 정수 구간이라 34.5 mph 같은 값이 비어 있습니다. `25 미만 / 25 이상 35 미만 / 35 이상 45 미만 / 45 이상 55 미만 / 55 이상`으로 읽습니다.
- 강우·강설 표에서 구간 끝이 겹치는 값(강우 0.25·0.50, 강설 1.0·2.0)은 더 높은 등급으로 분류합니다. 단 No Travel은 표기대로 초과일 때만 적용합니다(강우 1.00, 강설 3.0은 Severe).

**체크포인트와 구간 마일 계산**

- 샘플링 간격(10 / 25 / 50마일)은 사용자가 고릅니다. 기본값은 25마일입니다.
- 체크포인트는 출발지(0마일), 샘플링 간격마다, 도착지에 둡니다.
- **심각/높음 마일은 체크포인트 개수가 아니라 체크포인트 사이의 구간 거리로 계산합니다.** 각 체크포인트는 앞뒤 체크포인트와의 중간 지점까지를 대표하고, 그 길이를 해당 체크포인트의 등급에 합산합니다. 등급별 마일을 모두 더하면 경로 전체 거리와 같습니다.
- 평균 위험도는 등급을 숫자(Low 0, Moderate 1, High 2, Severe 3, No Travel 4)로 바꿔 구간 길이로 가중평균한 값입니다.
- 간격이 날씨를 얼마나 촘촘히 보는지를 정하므로, 간격에 따라 숫자가 달라질 수 있습니다: 폭 15마일의 폭풍은 50마일 간격의 두 체크포인트 사이로 빠질 수 있고 10마일 간격에서는 잡힙니다. 10마일이 가장 정밀하고 가장 느립니다.
- **도착 예상 시각은 쉬지 않고 달린다고 가정합니다.** 출발 시각에 라우팅 서비스가 준 그 지점까지의 주행 시간(트럭 속도, 그리고 출발이 지금과 가까우면 실시간 교통)을 더한 값입니다. 휴식과 주유는 반영하지 않고, 날씨가 트럭을 늦추지도 않습니다. 그래서 하루가 넘는 여행에서는 뒤쪽 도착 예상 시각이 실제보다 이릅니다.

**경로 추천**

- 4개 기준을 순서대로 비교하고, 앞 기준이 동점일 때만 다음 기준을 봅니다. 가중치 점수로 섞지 않습니다.
- 심각 마일, 높음 마일, 평균 위험도는 **화면용으로 반올림한 값이 아니라 계산한 값 그대로** 비교합니다: 카드에는 둘 다 25로 보여도 심각 24.6마일이 25.4마일을 이기고, 그때 이유 문장은 소수 자리를 보여줍니다("24.6 vs 25.4"). 이동 시간은 분 단위로 비교합니다. 그래도 이동 시간이 결정하는 경우는 흔합니다. 잔잔한 날에는 모든 경로의 심각 마일·높음 마일·평균이 정확히 0이기 때문입니다. 모든 값이 같으면 라우팅 서비스가 먼저 준 경로가 이깁니다.
- No Travel 구간이 하나라도 있는 경로는 추천에서 제외합니다. 3개 경로 모두 해당하면 추천하지 않고 사유를 보여줍니다.

**날씨 예보**

- 날씨는 실시간이 아니라 예보 기준입니다. 각 체크포인트의 날씨는 트럭의 도착 예상 시각으로 조회합니다.
- 예보는 정시 단위로 옵니다. **풍속**은 한 순간의 값이므로 체크포인트는 도착 예상 시각에 **가장 가까운 정시**를 사용합니다(정확히 30분이면 늦은 쪽). **강우·강설**은 한 시간 동안의 양이므로 **도착 시각을 포함하는 한 시간**을 사용합니다: 12:20에 도착하면 12:00부터 13:00까지 내리는 양(시간당 인치)입니다.
- 강우는 예보의 rain과 showers를 더한 값입니다. 강설은 새로 쌓이는 눈의 깊이(인치)이며 물로 환산한 양이 아닙니다.
- 예보는 약 15일 앞까지 있습니다. 출발 일시의 상한은 따로 두지 않습니다: 필요한 시각이 예보 끝을 넘을 때만 거부하고, 예보가 언제까지 있는지 메시지로 알려줍니다.
- 예보 데이터가 없을 때 **0으로 처리하지 않습니다.** 필요한 시각이 예보 끝을 넘었거나 날씨 서비스가 실패하면 위험 등급 대신 오류를 보여줍니다.
- heatmap 슬라이더의 0시간은 출발 일시(가장 가까운 정시로 맞춘 값)입니다. 어느 시점의 예보인지 알 수 있도록 슬라이더 옆에 날짜·시각을 함께 표시합니다.
- heatmap은 **경로와 같은 위험도 척도**를 연속으로 보여줍니다: 풍속·강우·강설 중 가장 나쁜 것을 표의 임계값 사이에 놓은 값이고(적재 규칙 포함), 경로에서 40마일 이내에 약 34마일 간격으로 놓은 격자 지점에 그립니다. heatmap은 슬라이더 시각의 날씨를 모든 곳에 한꺼번에 보여주고, 경로의 색은 트럭이 각 지점에 도착할 때의 날씨입니다. 둘은 서로 다른 질문에 답하므로 같은 장소에서도 다를 수 있습니다.

## 기술 스택

- Frontend: React + TypeScript (Vite) + MapLibre (WebGL 지도)
- Backend: Django + Django REST Framework (Django 관리자 페이지 없음: PDF가 요구하지 않고 백엔드가 데이터를 저장하지 않음)
- 외부 API (third-party)
  - 경로 · 장소: [TomTom](https://developer.tomtom.com/) Routing API (트럭 모드), Search API (From / To 목록과 입력한 글자는 Fuzzy Search, "내 위치"는 역지오코딩)
  - 날씨 예보: [Open-Meteo](https://open-meteo.com/) (CC BY 4.0)
