# Spotter — Weather-Aware Truck Routing

[English](./README.md) · 영문 `README.md`의 한국어판입니다. 영문이 기준입니다.

트럭 운전자가 **날씨, 적재 중량, 이동 시간**을 고려해 가장 안전한 경로를 고를 수 있도록 돕는 웹 앱입니다. (React + Django)

## 이 앱이 하는 일

1. **입력 받기** — 출발지/도착지, 출발 일시, 적재 중량을 입력합니다.
2. **경로 3개 생성** — routing API로 대안 경로 3개를 만듭니다.
3. **경로 위 날씨 확인** — 경로를 10 / 25 / 50마일 간격으로 나누고, 트럭이 각 지점에 **도착할 예상 시각** 기준의 날씨(풍속·강우·강설)를 가져옵니다.
4. **위험도 판정** — 날씨를 `Low / Moderate / High / Severe / No Travel`로 분류하고, 적재 중량이 무거울수록 강풍 구간의 위험 등급을 높입니다.
5. **최적 경로 추천** — 아래 순서로 비교해 가장 안전한 경로를 추천합니다.
   1. Severe 구간이 가장 짧은 경로
   2. High 구간이 가장 짧은 경로
   3. 평균 위험도가 가장 낮은 경로
   4. 이동 시간이 가장 짧은 경로
6. **지도 시각화** — 모든 경로, 체크포인트, 위험 수준, 도착 예상 시각(ETA), 경로 요약을 지도에 표시하고, 경로 주변 **날씨 heatmap**을 **0–48시간 forecast 슬라이더**로 확인할 수 있습니다.

## 위험 판정 요약

| 조건 | Low | Moderate | High | Severe | No Travel |
|---|---|---|---|---|---|
| 풍속 | < 25 mph | 25–34 | 35–44 | 45–54 | ≥ 55 mph |
| 강우 | < 0.10 in/hr | 0.10–0.25 | 0.25–0.50 | 0.50–1.00 | > 1.00 |
| 강설 | < 0.5 in/hr | 0.5–1.0 | 1.0–2.0 | 2.0–3.0 | > 3.0 |

적재 규칙:

- 풍속 ≥ 55 mph → 적재량과 관계없이 **No Travel**
- 풍속 45–54 mph + 적재 > 30,000 lb → **No Travel**
- 풍속 35–44 mph + 적재 > 40,000 lb → **Severe**

## 화면 구성

- **지도** — 조용한 회색 베이스맵 위에 경로 3개를 함께 보여줍니다. 선택한 경로는 출발지에서 도착지까지 그려지고(짧은 애니메이션), 경로선은 위험도에 따라 구간별로 색이 다르며, 나머지 경로는 평범한 회색 선입니다. 체크포인트마다 위험 등급 색의 원 안에 날씨 그림(맑음, 약한 비, 비, 눈, 바람)이 표시되고, 범례는 항상 보입니다.
- **경로 카드** — 경로마다 숫자 4개만 보여줍니다: 심각(Severe) 마일 / 높음(High) 마일 / 평균 위험 / 소요 시간. (화면 문구는 영어: `Severe mi`, `High mi`, `Avg risk`, `Duration`)
- **추천 이유** — 추천 경로에 이유를 한 줄로 표시합니다. (예: "0 severe miles, 20 min slower than Route B")
- **체크포인트** — 각 체크포인트에 도착 예상 시각(ETA)과 그 시각의 날씨, 위험 등급을 함께 보여줍니다. 지도나 목록에서 하나를 누르면 풍속·강우·강설이 값과 등급이 있는 그림 타일 세 개로 나타납니다.
- **운행 금지 경고** — No Travel 구간이 있으면 경고 배너로 크게 표시합니다.
- **forecast 슬라이더** — 0–48시간 슬라이더를 움직이면 날씨 heatmap과 지도 위 트럭 예상 위치가 함께 바뀝니다. 0시간은 출발 시간대(출발 시각을 가장 가까운 정시로 맞춘 값)이고, 고른 시각의 날짜·시간이 슬라이더 옆에 표시됩니다. 48시간 전체를 한 번에 받아 두므로 슬라이더를 움직여도 서버를 호출하지 않습니다.

## 규칙 해석과 가정

과제 문서가 명시하지 않은 부분은 아래와 같이 정했습니다.

**입력**

- 주소는 미국 안에서만 찾고 **첫 번째 일치 결과**를 사용합니다. 찾은 이름을 화면에 보여주므로 잘못 찾은 경우를 알아볼 수 있습니다(예: "Toronto, Canada"는 캔자스의 Toronto로 찾아집니다).
- 5분 전까지의 출발 일시는 받습니다. 폼의 "지금"은 서버에 닿을 때 이미 몇 초 지나 있기 때문입니다. 그보다 이전은 거부합니다.
- 출발지와 도착지가 같은 장소면 거부합니다.

**위험 등급**

- 체크포인트의 등급은 풍속·강우·강설 등급 중 **가장 높은 것**입니다. 적재 규칙은 이 등급을 올리기만 하고 내리지 않습니다.
- 풍속은 지속 풍속(sustained wind speed)을 사용합니다. 돌풍(gust)은 사용하지 않습니다.
- 풍속 표는 정수 구간이라 34.5 mph 같은 값이 비어 있습니다. `25 미만 / 25 이상 35 미만 / 35 이상 45 미만 / 45 이상 55 미만 / 55 이상`으로 읽습니다.
- 강우·강설 표에서 구간 끝이 겹치는 값(강우 0.25·0.50, 강설 1.0·2.0)은 더 높은 등급으로 분류합니다. 단 No Travel은 표기대로 초과일 때만 적용합니다(강우 1.00, 강설 3.0은 Severe).

**체크포인트와 구간 마일 계산**

- 샘플링 간격(10 / 25 / 50마일)은 사용자가 고릅니다. 기본값은 25마일입니다.
- 체크포인트는 출발지(0마일), 샘플링 간격마다, 도착지에 둡니다.
- **심각/높음 마일은 체크포인트 개수가 아니라 체크포인트 사이의 구간 거리로 계산합니다.** 각 체크포인트는 앞뒤 체크포인트와의 중간 지점까지를 대표하고, 그 길이를 해당 체크포인트의 등급에 합산합니다. 등급별 마일을 모두 더하면 경로 전체 거리와 같습니다.
- 평균 위험도는 등급을 숫자(Low 0, Moderate 1, High 2, Severe 3, No Travel 4)로 바꿔 구간 길이로 가중평균한 값입니다.

**경로 추천**

- 4개 기준을 순서대로 비교하고, 앞 기준이 동점일 때만 다음 기준을 봅니다. 가중치 점수로 섞지 않습니다.
- 동점은 화면에 표시하는 값으로 판정합니다(마일은 1마일, 평균 위험도는 소수 둘째 자리, 이동 시간은 분 단위). 반올림은 절반을 올립니다(24.5마일은 25로 표시). 모든 값이 같으면 라우팅 서비스가 먼저 준 경로가 이깁니다.
- No Travel 구간이 하나라도 있는 경로는 추천에서 제외합니다. 3개 경로 모두 해당하면 추천하지 않고 사유를 보여줍니다.

**날씨 예보**

- 날씨는 실시간이 아니라 예보 기준입니다. 각 체크포인트의 날씨는 트럭의 도착 예상 시각으로 조회합니다.
- 체크포인트는 도착 예상 시각에 **가장 가까운 정시**의 예보를 사용합니다(정확히 30분이면 늦은 쪽). 풍속은 그 정시의 값이고, 강우·강설은 직전 1시간의 양(시간당 인치)입니다.
- 예보 데이터가 없을 때 **0으로 처리하지 않습니다.** 필요한 시각이 예보 끝을 넘었거나 날씨 서비스가 실패하면 위험 등급 대신 오류를 보여줍니다.
- heatmap 슬라이더의 0시간은 출발 일시(가장 가까운 정시로 맞춘 값)입니다. 어느 시점의 예보인지 알 수 있도록 슬라이더 옆에 날짜·시각을 함께 표시합니다.
- 도착 예상 시각이 날씨 예보 범위를 벗어나면 값을 추정하지 않고 오류로 알립니다.

## 기술 스택

- Frontend: React + TypeScript (Vite) + MapLibre (WebGL 지도)
- Backend: Django + Django REST Framework (Django 관리자 페이지 없음: PDF가 요구하지 않고 백엔드가 데이터를 저장하지 않음)
- 외부 API (third-party)
  - 경로 · 주소 변환: [TomTom](https://developer.tomtom.com/) Routing API (트럭 모드), Geocoding API
  - 날씨 예보: [Open-Meteo](https://open-meteo.com/) (CC BY 4.0)
